# 实际产品演示（最终版）

最终视频位于本地 `reports/portfolio/AI-Ecommerce-Insight-demo.mp4`。八段实际画面依次展示数据总览、负向筛选、问题优先级、履约线索、历史批准策略、报告、300 条 AI 标注和 300 条研究工作区。独立无头浏览器录制，配离线中文旁白与标题字幕；没有控制用户鼠标或键盘，没有新增付费模型请求。演示模式隐藏原始评论及逐条引用。

292/300 是首次契约通过，8 条为 AI 补充，不是人工答案或准确率。新研究策略仍待审核，历史五项计划批准不代表已执行。以下为调整为 AI 代标前的历史脚本，仅作过程存档。

视频应录制真实本地产品操作。以下是脚本，不是已录制视频。公开录制使用有权展示或人工编写并明确标注的示例，不展示原始未授权评论、密钥、邮箱、其他浏览器标签及私人聊天。

| 时间 | 画面与操作 | 解说要点 |
|---|---|---|
| 0:00—0:20 | 数据总览 | 说明服饰评论场景、本地原型与样本口径；不外推平台表现 |
| 0:20—0:50 | 消费者洞察，筛选负向评论，查看一条完整证据 | 模型标签引用原文，校验通过不等于答案正确 |
| 0:50—1:15 | 问题与优先级 | 展示频次、负向占比及权重敏感性，经营数据缺失保留未知 |
| 1:15—1:40 | 履约线索 | 无订单与物流记录，只能提出核查问题 |
| 1:40—2:15 | 策略中心，展示已批准版本 | 核查计划经过人工修订；批准不等于已执行整改 |
| 2:15—2:35 | 报告中心，生成并下载 PDF | 只包含当前有效批准版本；修改证据后需重新生成 |
| 2:35—3:00 | 人工标注与评估，停留开发集 | 展示盲标入口与进度，说明最终指标仍待实测 |
