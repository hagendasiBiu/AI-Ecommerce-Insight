# 原始字段说明

分析粒度：CSV 一行是一条语料记录，不能保证对应唯一消费者、商品或订单。各项实际类型和缺失数参见质量报告。

| 字段 | 含义 | 使用限制 |
|---|---|---|
| cat | 发布者给定的类别 | 服饰筛选使用 `衣服`，其中也可能混入其他品类文本 |
| label | 正负情感标签，1 正向、0 负向 | 不是星级评分，不直接作为人工评估真值，不向待评估 LLM 提供该标签 |
| review | 中文评论正文 | 保留原文，后续对空白、重复、个人信息等单独检查 |

不存在源字段 review_id；后续创建的追踪 ID 必须标为项目派生字段。当前没有商品 ID、价格、订单、采集时间、点赞数及推荐标记。

空值检查与空白字符串检查分开；完全重复行和仅正文相同的重复行也分开统计，以便在清洗阶段做不同处理。
